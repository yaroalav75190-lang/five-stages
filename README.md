# Камилла, это про тебя

Одностраничная инфографика, сделанная под конкретного человека: шесть всадников операционки,
отдельный блок про кредитную карту, тест на 14 пунктов, пять стадий, бинго совещания,
разговорник и развилка.

Один файл `index.html`, без зависимостей кроме шрифтов Google. Интерактив (тест, бинго,
разговорник) работает на чистом JS; если скрипт не выполнится, страница всё равно читается.

## Публикация на GitHub Pages

1. Создать репозиторий на github.com.
2. В этой папке:

```bash
git init -b main
git add .
git commit -m "infographic"
git remote add origin https://github.com/USERNAME/REPO.git
git push -u origin main
```

3. Settings → Pages → Source: `Deploy from a branch` → Branch: `main` / `root`.
4. Через 1–2 минуты сайт будет по адресу `https://USERNAME.github.io/REPO/`

## Важно перед публикацией

Страница называет реальных людей по фамилии и имени и описывает конкретного работодателя.
GitHub Pages открыт всему интернету и индексируется поисковиками. Если ссылка нужна только
для одного человека — публиковать это публично не стоит: смотри варианты в переписке
(приватный Artifact или `noindex`).
